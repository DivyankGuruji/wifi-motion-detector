The main aim of this project is to detect any movement and presence of any object between the WiFi transmitter and receiver.

If there is something present between the TX and RX then the RSSI (Received Signal Strength Indicator) value changes, which shows that there is some movement or someones presence.

## Components Used
In this project I had used a 2.4GHz WiFi router as signal transmitter and an ESP32-WROOM-32 as WiFi signal receiver. ESP32 is connected to laptop and shows the live RSSI Value directly on the serial monitor.

## ESP32-WROOM-32
The ESP32-WROOM-32 is a powerful, low-cost System-on-Chip (SoC) module by Espressif Systems. It integrates Wi-Fi, dual-mode Bluetooth (Classic and BLE), and a dual-core 32-bit microprocessor.

## WiFi Router
A Wi-Fi router is a networking device that acts as the central hub for your home or office internet. It connects to your modem to receive an internet signal from your Internet Service Provider (ISP) and broadcasts that signal wirelessly (via Wi-Fi) or through wired cables to your devices.
